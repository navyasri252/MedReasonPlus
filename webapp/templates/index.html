A THOUGHTFUL REVIEW, STEP BY STEP

From image to evidence trail

Explore the different signals used in the research workflow, and see where the analysis agrees, differs, or remains uncertain.

01

Adaptive Multimodal Fusion

Four feature streams fused through an attention gate that learns to weight each modality dynamically per case. No hard-coded weights — the model decides at runtime which evidence to trust.

768 + 384 + 384 + 64 → Attention Gate → 256 → Decision
02

GradCAM++ Explainability

Gradient-weighted activation maps show which exact pixel regions drove the decision. CNN branch → GradCAM++. ViT branch → EigenCAM.

Layer: features[7][-1].block[0]
03

Knowledge Graph Verification

12 clinical findings matched against the report text. Scores evidence on a −1.0 to +1.0 scale and classifies as CONSISTENT, INCONSISTENT, or UNCERTAIN.

12 findings · −1.0 (normal) to +1.0 (pneumonia)
04

Conflict Detection

Four parallel checks: model vs KG, image vs text, high confidence against uncertain evidence, attention ignoring strong text signal. Severity: NONE / LOW / MEDIUM / HIGH.

4 conflict types · 4 severity levels
05

Multi-Agent Reasoning

Three specialised agents share a context object with all features, heatmap, KG result, and conflict data. Sequential reasoning — each agent reads the previous output.

Shared memory · Sequential · Structured report
